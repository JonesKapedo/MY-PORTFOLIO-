## Technology Stack

This enterprise website is built with modern technologies for optimal performance and scalability:

- **Framework**: React 19 + TypeScript
- **Routing**: TanStack Router
- **Styling**: Tailwind CSS 4 + Custom Design System
- **Components**: Radix UI primitives
- **Build Tool**: Vite 8
- **Deployment**: Vercel-ready (SSR/SSG)
- **Database**: PostgreSQL with Kysely ORM
- **Authentication**: Better Auth

## Development

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/JonesKapedo/MY-PORTFOLIO-.git
cd MY-PORTFOLIO-

# Install dependencies
npm install

# Run development server
npm run dev
```

The application will be available at `http://localhost:8080`

### Available Scripts

```bash
npm run dev          # Start development server
npm run build        # Build for production
npm run preview      # Preview production build
npm run typecheck    # Run TypeScript checks
npm run lint         # Lint codebase
npm run format       # Format with Prettier
npm test            # Run tests
```

### Project Structure

```
src/
├── routes/          # Page routes and components
│   ├── index.tsx    # Homepage
│   ├── services.tsx # Services page
│   ├── portfolio.tsx# Portfolio & case studies

├── components/      # Reusable UI components
├── lib/            # Utilities and configuration
│   └── site.ts     # Site content and data
└── styles.css      # Global styles
```

## Deployment

### Vercel (Recommended)

This project is optimized for Vercel deployment:

```bash
# Deploy to Vercel
vercel deploy

# Deploy to production
vercel --prod
```

### Environment Variables

Create a `.env` file with required variables:

```env
DATABASE_URL=postgresql://...
BETTER_AUTH_SECRET=your-secret-key
BETTER_AUTH_URL=https://your-domain.com
```
